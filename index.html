📘 Panduan Persyaratan Data Affalitycs

Ikuti checklist berikut saat mengunduh data agar semua metrik (Campaign, Ad Set, Ad, Real CPC, dan Kebocoran Trafik) terhitung otomatis.

📘 1. Facebook Ads Report WAJIB
📍 Sumber: Meta Ads Manager ➔ Tab Iklan (Ads)
  1. Masuk ke Meta Ads Manager lalu pastikan Anda berada di tab Iklan (Ads) (level ad, bukan campaign/adset).
  2. Buka menu dropdown Kolom (Columns) ➔ pilih Sesuaikan Kolom (Customize Columns).
  3. Pastikan 9 kolom wajib berikut dicentang:
    Campaign name Ad set name Ad name (Sub_ID) Amount spent Link clicks Landing page views Impressions CPC CTR
  4. Buka menu Rincian (Breakdown) ➔ Berdasarkan Waktu ➔ pilih Hari (Day) (sangat disarankan agar data harian dan tren dapat dianalisis presisi).
  5. Klik tombol Ekspor di pojok kanan atas ➔ simpan dalam format .xlsx atau .csv.
🛍️ 2. Shopee Affiliate Report (Komisi) WAJIB
📍 Sumber: Portal Shopee Affiliate ➔ Menu Laporan Konversi
  1. Login ke portal Shopee Affiliate Program di web browser.
  2. Pilih menu Laporan ➔ Laporan Konversi.
  3. Tentukan rentang tanggal yang sama persis dengan periode iklan Facebook Ads Anda.
  4. Klik tombol Ekspor (.csv) dan unduh file hasil ekspor.
  5. 💡 Kunci Pencocokan Otomatis: Saat men-generate link affiliate di Shopee, selalu sematkan kode identitas iklan pada kolom Sub_ID / Tag_link1 atau Tag_link3 (contoh: cp01, gacoan02). Affalitycs akan langsung mencocokkan biaya iklan FB dengan komisi Shopee tanpa perlu mapping manual!
🌐 3. Shopee Website Click Report SANGAT DISARANKAN
📍 Sumber: Portal Shopee Affiliate ➔ Menu Laporan Klik Situs Web
  1. Di portal Shopee Affiliate, buka menu Laporan ➔ Laporan Klik Situs Web.
  2. Pilih rentang tanggal yang sama lalu klik Ekspor (.csv).
  3. 🎯 Mengapa File Ini Sangat Krusial? File ini mencatat berapa banyak pengunjung FB yang benar-benar berhasil mendarat di Shopee. Dengan mengunggah file ini, Affalitycs dapat membuka analisis Real CPC (biaya per pengunjung riil) dan mengukur % Kebocoran Trafik (klik yang hilang sebelum membuka Shopee).

Memahami Funnel Konversi 3-Tahap & Real CPC

Banyak pengiklan affiliate terjebak ilusi "CPC FB Murah" (misal Rp 100/klik), tetapi tidak menyadari banyak klik yang gagal memuat tautan Shopee.

1
Tahap 1: Klik Iklan Facebook (Outbound Clicks)

Jumlah klik tautan yang tercatat di sistem Meta Ads ketika audiens tertarik dan menekan iklan Anda di Facebook atau Instagram.

⚠️ KEBOCORAN TRAFIK (% BOCOR) — PENGUNJUNG MENTAL DI JALAN

Selisih antara Klik FB dan Klik yang benar-benar tercatat di Shopee. Kebocoran terjadi akibat loading lambat, koneksi pengguna terputus, kegagalan deep-link pembuka aplikasi Shopee, atau pengguna membatalkan browser sebelum produk tampil.

% Kebocoran = ((Klik Iklan FB - Klik Shopee) ÷ Klik Iklan FB) × 100%
2
Tahap 2: Klik Sampai Shopee (Inbound Clicks) & Real CPC

Jumlah pengunjung nyata yang berhasil mendarat di toko atau halaman produk Shopee Anda. Di tahap inilah biaya riil per calon pembeli dihitung:

Real CPC = Total Biaya Iklan (Spend) ÷ Klik Riil Shopee
💡 Simulasi: Jika Anda menghabiskan Rp 100.000 untuk 1.000 Klik FB (CPC FB = Rp 100), namun hanya 500 klik yang sampai ke Shopee (Kebocoran 50%), maka Real CPC Anda sebenarnya adalah Rp 200 per calon pembeli (2x lipat lebih mahal!).
3
Tahap 3: Pesanan Valid (Orders) & Shopee CVR

Pengunjung yang memutuskan membeli produk dan transaksinya berhasil diverifikasi oleh Shopee hingga menghasilkan komisi affiliate.

Shopee CVR = (Total Pesanan ÷ Klik Riil Shopee) × 100%

Strategi Pengambilan Keputusan (Master Decision Table)

Master Decision Table menyatukan performa Facebook Ads dan Shopee Affiliate dalam satu baris per campaign/ad. Gunakan aturan lampu lalu lintas (Traffic Light System) berikut untuk mengevaluasi efektivitas iklan Anda:

🟢 ROAS ≥ 2.0x Sangat Profit (Scale Up)

Komisi yang didapat minimal 2x lipat dari total modal biaya iklan.

Aksi Rekomendasi:
  • Naikkan budget harian secara bertahap (10% - 20% per hari) agar tidak merusak learning phase.
  • Duplikat ad set pemenang ke audiens baru (Lookalike atau broad target).
🟡 ROAS 1.0x – 2.0x Break-Even / Profit Tipis (Optimasi)

Iklan masih menghasilkan keuntungan tipis atau balik modal.

Aksi Rekomendasi:
  • Periksa % Kebocoran link di funnel; jika >30%, perbaiki deep link atau gunakan landing page perantara yang ringan.
  • Uji hook video/gambar baru (3 detik pertama) untuk menekan CPC FB lebih murah.
🔴 ROAS < 1.0x Rugi (Evaluasi & Cut Loss)

Biaya iklan lebih besar daripada komisi affiliate yang diperoleh.

Aksi Rekomendasi:
  • Jika biaya iklan sudah melampaui 1x - 2x target CPO tanpa menghasilkan konversi, segera matikan (pause) iklan.
  • Ganti penawaran dengan produk komisi ekstra (Shopee Xtra Commission) yang bermargin lebih tinggi.
Fitur Cerdas Master Table:
  • Kolom Sticky (Nama Campaign): Kolom nama campaign tetap terkunci di sebelah kiri saat Anda menggeser tabel ke samping kanan.
  • Default Urutan Biaya Terbesar: Iklan dengan biaya tertinggi otomatis berada di paling atas karena memiliki risiko modal terbesar.
  • Alur Funnel Alami (Kiri ke Kanan): Spend ➔ Klik FB ➔ Klik Shopee ➔ % Bocor ➔ Orders ➔ CPC FB ➔ Real CPC ➔ CPO ➔ Komisi ➔ Profit ➔ ROAS.

Fitur Cepat untuk Efisiensi Optimasi Harian

Maksimalkan waktu Anda dengan berbagai shortcut dan alat bantu otomatis di Affalitycs:

🎯 Drill-Down Campaign ➔ Produk

Klik nama campaign pada kolom pertama Master Table (misal cp03 ↗). Layar otomatis menggulir ke Tabel Produk dan menyaring produk-produk yang dibeli melalui campaign tersebut.

📋 Salin Ringkasan WhatsApp (1-Klik)

Klik tombol Salin Ringkasan di bar atas. Laporan performa harian berformat emoji profesional langsung tersalin ke clipboard, siap dikirimkan ke tim, klien, atau grup ads Anda.

⚙️ Custom Pajak / Fee Akun (%)

Jika menggunakan agency ad account (fee 3-7%) atau terkena PPN 11%, ketikkan persentasenya di input bar. Seluruh spend, profit bersih, dan ROAS akan terhitung ulang secara instan.

🕒 Golden Hours (Jam Emas Konversi)

Grafik distribusi jam (00:00 - 23:00 WIB) menunjukkan jam-jam spesifik di mana calon pembeli paling banyak checkout. Sangat bermanfaat untuk strategi Dayparting iklan.

💾 Backup & Restore Riwayat JSON

Ekspor sesi analisis ke file .json melalui menu titik tiga (⋮). Anda dapat membuka kembali laporan kapan saja tanpa perlu mencari dan mengunggah ulang file mentah.

🌗 Mode Gelap (Dark Mode)

Bekerja larut malam menganalisis data? Aktifkan dark mode di pojok kanan atas untuk kenyamanan mata dan visual kontras tinggi.

🔗 Hubungkan Tag Shopee & Iklan Facebook (Mapping)

Beberapa Tag dari Shopee (Tag_link1 / Tag_link3) tidak cocok otomatis dengan nama di Facebook Ads. Tentukan pasangannya di bawah ini agar Spend & Komisi terhubung, atau klik Lewati jika tag tersebut adalah traffic organik.
