📘 Panduan Persyaratan Data Affalitycs

Ikuti checklist berikut saat mengunduh data agar semua metrik (Campaign, Ad Set, Ad, Real CPC, dan Kebocoran Trafik) terhitung otomatis.

1. Facebook Ads Report WAJIB
  1. Buka Meta Ads Manager lalu masuk ke tab Iklan (Ads).
  2. Buka menu Kolom (Columns) ➔ pilih Sesuaikan Kolom (Customize Columns).
  3. Centang kolom-kolom berikut:
    Campaign name Ad set name Ad name (Tag Shopee) Amount spent Link clicks Landing page views Impressions CPC CTR
  4. Buka menu Rincian (Breakdown) ➔ Berdasarkan Waktu (By Time) ➔ pilih Hari (Day) (sangat disarankan untuk akurasi harian).
  5. Klik tombol Ekspor ➔ simpan dalam format .xlsx atau .csv.
2. Shopee Affiliate Report (Komisi) WAJIB
  1. Buka portal Shopee Affiliate Program.
  2. Pilih menu Laporan ➔ Laporan Konversi.
  3. Tentukan rentang tanggal yang sama dengan periode iklan Facebook Anda.
  4. Pastikan saat membuat link affiliate, Anda menyematkan Sub_ID pada Tag_link1 atau Tag_link3 (contoh: gacoan01, pamper03).
  5. Klik tombol Ekspor dan unduh file .csv.
3. Shopee Website Click Report SANGAT DISARANKAN
  1. Di portal Shopee Affiliate Program, buka menu Laporan ➔ Laporan Klik Situs Web.
  2. Pilih rentang tanggal yang sama lalu klik Ekspor (file .csv).
  3. Manfaat file ini: Mengukur berapa klik iklan FB yang benar-benar mendarat di Shopee untuk menghitung Real CPC dan % Klik Hilang (Bocor) secara akurat.

📖 Tutorial & Petunjuk Penggunaan Affalitycs

Panduan praktis mulai dari persiapan data hingga strategi membaca dashboard untuk meningkatkan profit affiliate Anda.

📘 1. Facebook Ads Report WAJIB

Ekspor dari Meta Ads Manager pada level Iklan (Ads):

  1. Buka menu Kolom ➔ Sesuaikan Kolom ➔ Centang: Campaign name, Ad set name, Ad name, Amount spent, Link clicks, Landing page views, Impressions, CPC, CTR.
  2. Buka menu Rincian (Breakdown) ➔ Berdasarkan Waktu ➔ pilih Hari (Day).
  3. Klik Ekspor ➔ simpan format .xlsx atau .csv.
🛍️ 2. Shopee Affiliate Report (Komisi) WAJIB

Ekspor dari portal Shopee Affiliate Program:

  1. Pilih menu Laporan ➔ Laporan Konversi.
  2. Tentukan rentang tanggal yang sama dengan iklan FB Anda ➔ Klik Ekspor (.csv).
  3. Tips: Saat membuat link affiliate di Shopee, sematkan Sub_ID pada Tag_link1 (contoh: gacoan01, pamper03) yang cocok dengan nama Ad Facebook Anda.
🌐 3. Shopee Website Click Report SANGAT DISARANKAN

Dari portal Shopee Affiliate ➔ menu Laporan Klik Situs Web ➔ Ekspor (.csv).

Fungsi vital: Mengukur berapa klik FB yang benar-benar mendarat di Shopee untuk menghitung Real CPC dan % Kebocoran Trafik.

🔍 Memahami Funnel Konversi 3-Tahap

Banyak pengiklan FB hanya terpaku pada CPC FB murah (misal Rp 100/klik), tetapi tidak menyadari banyak klik yang gagal memuat link Shopee.

1. Klik Iklan FB ➔ Jumlah klik link yang dicatat Meta.
⬇ Kebocoran (% Bocor): Pengunjung mental di tengah jalan sebelum membuka Shopee.
2. Klik Sampai Shopee ➔ Pengunjung yang sukses membuka halaman produk di Shopee.
⬇ Shopee CVR: Rasio checkout dari pengunjung yang sudah masuk.
3. Pesanan (Orders) ➔ Pesanan valid yang menghasilkan komisi affiliate.

Real CPC = Biaya riil per 1 pengunjung yang mendarat di Shopee. Jika kebocoran tinggi (misal 50%), maka Real CPC Anda sebenarnya 2x lipat lebih mahal daripada CPC FB!

📊 Cara Mengevaluasi Iklan di Master Table

  • Kolom Campaign Sticky: Saat menggeser tabel ke kanan, nama campaign tetap terkunci di kiri.
  • Alur Funnel Alami: Spend ➔ Klik FB ➔ Klik Shopee ➔ % Bocor ➔ Orders ➔ CPC FB ➔ Real CPC ➔ CPO ➔ Komisi ➔ Profit ➔ ROAS.
  • Default Sort Spend Terbesar: Iklan dengan biaya terbesar otomatis di atas karena memiliki risiko modal tertinggi.
  • Indikator ROAS:
    • ROAS ≥ 2x (Hijau): Sangat menguntungkan, siap scale up budget.
    • ROAS 1x - 2x (Kuning): Break-even / untung tipis, optimasi materi iklan & kebocoran link.
    • ROAS < 1x (Merah): Rugi (biaya iklan melebihi komisi), pertimbangkan untuk dimatikan.

⚡ Fitur Cepat untuk Optimasi Harian

🎯 Drill-Down Campaign ke Produk:

Klik nama campaign di kolom pertama Master Table (misal cp03 ↗). Layar akan otomatis menggulir ke Tabel Produk dan menyaring produk yang terjual lewat campaign tersebut.

📋 Salin Ringkasan (WA):

Klik tombol Salin Ringkasan di bar atas. Semua ringkasan performa otomatis tersalin rapi dengan format WhatsApp siap kirim ke tim/grup.

➕ Custom Pajak / Fee Akun (%):

Jika Anda menyewa akun agency (misal fee 5%) atau terkena PPN 11%, masukkan persentasenya di kotak input. Seluruh biaya, profit, dan ROAS langsung terhitung ulang secara presisi.

🕒 Jam Emas (Golden Hours):

Pantau jam berapa klik pengunjung berkonversi menjadi pesanan (00 - 23 WIB) untuk menentukan jadwal tayang iklan yang paling menguntungkan.

🔗 Hubungkan Tag Shopee & Iklan Facebook (Mapping)

Beberapa Tag dari Shopee (Tag_link1 / Tag_link3) tidak cocok otomatis dengan nama di Facebook Ads. Tentukan pasangannya di bawah ini agar Spend & Komisi terhubung, atau klik Lewati jika tag tersebut adalah traffic organik.
